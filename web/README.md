# Vaktija – web

React + TypeScript + Vite verzija aplikacije: današnja vremena, mjesečni i godišnji pregled s PDF-om, odabir grada ili vlastitog mjesta (država + koordinate).

```
npm install
npm run dev     # razvoj
npm run build   # produkcija → dist/
```

Fontovi `DejaVuSansCondensed*.ttf` u `public/` služe za PDF (bosanska slova) i moraju ostati tamo.
